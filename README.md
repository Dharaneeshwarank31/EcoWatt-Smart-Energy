# EcoWatt – Smart Electricity Monitoring & Prediction System

## Problem Statement

Campus buildings consume electricity at different levels throughout the day.
Understanding consumption patterns and identifying peak usage periods can help
with better electricity planning.

## Proposed Solution

EcoWatt is a web-based smart electricity monitoring and prediction prototype
designed to analyze energy usage, predict consumption, identify peak periods,
and support smarter electricity scheduling.

## Key Features

- AI Energy Predictor
- Live Energy Graph
- 7-Day Energy Forecast
- Appliance Calculator
- Electricity Bill Calculator
- Monthly Usage Summary
- Prediction History
- Smart Schedule
- IoT Sensor & Smart Meter Support

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js
- ESP8266 / IoT integration
